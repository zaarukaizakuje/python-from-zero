Module 1 — Your First Python Program

What is programming?

Programming means giving a computer instructions. Python is a programming language that lets us write those instructions in a readable way.

Your first program

print("Hello, world!")

print() tells Python to display something on the screen.

Module 2 — Variables

A variable stores information so that we can use it later.

name = "Scott"
age = 20
print(name)
print(age)

Text is called a string. Whole numbers are commonly stored as integers.

Module 3 — Input and Output

input() allows the user to enter information.

name = input("Enter your name: ")
print("Hello", name)

Important: input() normally gives you text. If you need a number, convert it.

age = int(input("Enter your age: "))
print(age + 1)

Mini Project — Age Checker Input

name = input("Enter your name: ")
age = int(input("Enter your age: "))

print("Hello", name)
print("Next year you will be", age + 1)

Module 4 — If Statements

Programs often need to make decisions. An if statement lets Python choose what to do based on a condition.

age = int(input("Enter your age: "))

if age >= 18:
    print("You are an adult")
else:
    print("You are under 18")

Notice the indentation. The indented lines belong to the if or else.

Mini Project — Pass or Fail

mark = int(input("Enter your mark: "))

if mark >= 50:
    print("PASS")
else:
    print("FAIL")
Quiz: What happens when mark = 40?

Module 5 — Functions

A function is a reusable block of code.

def greet():
    print("Hello!")

greet()

Functions can accept information called parameters.

def greet(name):
    print("Hello", name)

greet("Scott")

return sends a result back to the place where the function was called.

def add(a, b):
    return a + b

answer = add(5, 3)
print(answer)

Practice

Create a function called square that receives a number and returns the number multiplied by itself.

def square(number):
    return number * number
Quiz: What does return do?

Module 6 — Lists

A list stores multiple values in one variable.

subjects = ["Math", "Python", "English"]

print(subjects)
print(subjects[0])

Python starts counting list positions from 0.

Adding an item

subjects.append("Computing")

Practice

Module 7 — Loops

Loops repeat code.

for i in range(5):
    print(i)

This prints 0, 1, 2, 3 and 4.

You can also loop through a list:

subjects = ["Math", "Python", "English"]

for subject in subjects:
    print(subject)

Practice

Make a list of three games and use a for loop to print each one.

Module 8 — Final Project: Student Grade Calculator 🎓

Now combine variables, input, calculations, functions and conditions into one program.

Requirements

  • Ask for the student's name.
  • Ask for three marks.
  • Calculate the average.
  • Display PASS or FAIL.
  • Display a simple grade.

Starter code

name = input("Enter your name: ")

math = float(input("Enter Math mark: "))
python = float(input("Enter Python mark: "))
english = float(input("Enter English mark: "))

average = (math + python + english) / 3

print("Student:", name)
print("Average:", average)

if average >= 50:
    print("Status: PASS")
else:
    print("Status: FAIL")

Challenge

Add these grades:

  • 80–100 = A
  • 70–79 = B
  • 60–69 = C
  • 50–59 = D
  • Below 50 = F
