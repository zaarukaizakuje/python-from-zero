Module 2 — Variables & Data Types

A variable stores information. Python has several built-in data types.

name = "Scott"       # string
age = 20             # integer
height = 1.75        # float
is_student = True    # boolean

Use type() to check the type of any value:

print(type(age))     # <class 'int'>

Module 3 — Input & Output

input() lets the user type information.

name = input("Enter your name: ")

print("Hello", name, "- next year you'll be", age + 1)

Module 4 — Control Flow (If / Elif / Else)

mark = int(input("Enter your mark: "))

if mark >= 80:
    print("Grade A")
elif mark >= 70:
    print("Grade B")
elif mark >= 50:
    print("Pass")
else:
    print("Fail")

Indentation matters in Python — it defines which lines belong to which block.

Quiz: What runs when mark = 65?

Module 5 — Loops (For & While)

for i in range(5):
    print(i)

count = 0
while count < 3:
    print("Count is", count)
    count += 1

Module 6 — Functions
