# Python From Zero

A beginner-friendly online course website.

## Publish it for free

1. Open GitHub and create a new repository.
2. Upload `index.html`.
3. In the repository settings, enable GitHub Pages from the main branch/root folder.
4. GitHub will give you a public course URL.

Alternative: upload `index.html` to any static website host.

The course uses browser localStorage to save each learner's progress on their device.
